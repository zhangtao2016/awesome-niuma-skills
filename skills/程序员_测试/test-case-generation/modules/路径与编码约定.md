# 路径与编码约定

适用于本技能包内脚本：`generate_from_requirement.py`、`generate_xmind.py`、`convert_to_json.py`、`upload_to_blade.py`、`upload_analysis_to_blade.py` 等。

## 工作区 `public/`（配置与清单）

- **`public/config.json`**：Blade `api_token`、账号、`pre_docs_dir` / `post_docs_dir` 等（可选覆盖默认路径）。
- **`public/pre_docs/`**、**`public/post_docs/`**、**`public/templates/`**：前置参考、后置自查清单、内容 JSON 模板。默认技能包路径形态为 `<workspace>/<中间层目录>/skills/test-case-generation/`（中间层目录可为以 `.` 开头的目录，常见如 `.cursor`、`.claude`、`.trae`），脚本按“当前技能包目录向上三级”解析 `<workspace>/public/`；也可设环境变量 **`TEST_CASE_GENERATION_PUBLIC`** 指向自定义 `public` 目录绝对路径。

## 一需求一目录（工作区）

每个需求对应**独立文件夹**，集中放需求正文、分析/用例中间 JSON、以及生成的 XMind、分析 JSON、用例 MD、Blade 用例 JSON。路径须**先判定产品**，再落到该产品下的需求目录。

| 项 | 约定 |
|----|------|
| 产品目录 `<Product>` | **先判断归属产品**（如 MCP 返回字段、用户指定 `--product`、或任务上下文）；文件夹名与 **`public/pre_docs/<产品>/`**、脚本 **`--product <产品名>`** 一致（常见为英文短名，如 `HUI`） |
| 完整路径 | **`<workspace>/<Product>/<需求号>-<需求简述>/`** |
| 需求子目录名 | `<需求号>-<需求简述>`，半角 `-` 连接；简述 ≤10 字（可中文），勿含 `\ / : * ? " < > \|` |
| 需求文档 | 与需求子目录 **stem 相同** 的 `<需求号>-<需求简述>.md`（勿用与目录脱节的 `requirement.md`） |
| 脚本 | `generate_from_requirement.py` 第一个参数为需求文档**绝对路径**；`--output-dir` 指向**同一需求目录**（即含 `<Product>/<需求号>-<简述>/` 的完整路径） |
| 混放 | 不同需求号勿共目录，避免中间产物与生成文件互相覆盖 |

其它通用工作目录**建议英文命名**，降低 Windows 终端编码风险；**需求目录简述允许中文**。

示例（产品为 `HUI` 时）：

```
<workspace>/HUI/202602033246-弹框居中可拖拽/
├── 202602033246-弹框居中可拖拽.md
├── test_analysis_content.json
├── test_cases_content.json
├── test_analysis-<标题>.xmind / .json
├── test_cases-<标题>.md / .json
```

交付物文件名：`test_analysis-*`、`test_cases-*` 等由脚本 `sanitize_filename` 处理（中文等会变为安全文件名）。

## 调用路径

- 调用脚本时，需求文件、输出目录、`-A`/`-C` 内容文件等**优先绝对路径**；脚本内用 `pathlib.Path` 解析。

## Windows / PowerShell

- 多条命令用 **`;`**，不要用 `&&`。  
  例：`cd <workspace> ; python <skill>/scripts/generate_from_requirement.py "<需求绝对路径>"`

**含中文路径传参给 Python**（如 `upload_to_blade.py` 的 JSON 路径）：PowerShell/控制台常用 GBK，中文绝对路径可能在进入 `sys.argv` 前已乱码，表现为「JSON 文件不存在」且错误里路径是乱码——**非脚本读文件失败**；脚本侧已用 `pathlib` + UTF-8 读 JSON。

**稳妥做法**：在仓库根目录用 Python 拼路径（`\uXXXX` 表示中文），再 `exec` 上传脚本，避免在 Shell 里直接敲中文路径：

```text
python -c "import sys; from pathlib import Path; scripts = Path('<skill_scripts_abs_path>'); sys.path.insert(0, str(scripts)); p = Path('HUI') / '202602033246-\u5f39\u6846\u5c45\u4e2d\u53ef\u62d6\u62fd' / 'test_cases-202602033246_HUI_msgbox_\u5f39\u6846\u5c45\u4e2d\u4e0e\u62d6\u62fd\u7f29\u653e.json'; sys.argv = ['upload_to_blade.py', str(p.resolve()), '--product', 'HUI', '--timeout', '60']; exec((scripts / 'upload_to_blade.py').read_text(encoding='utf-8'))"
```

其中 `<skill_scripts_abs_path>` 为该技能包 `scripts` 目录绝对路径（可先在 Python 中 `Path(__file__).resolve().parent` 推导，或手工填写）。

按需替换分段路径、`--product` 等；已 `cd` 到 `scripts` 时可改用当前目录下的 `upload_to_blade.py`。**备选**：`Set-Location -LiteralPath` 进需求目录后传 `./xxx.json`；或 `cmd` + `chcp 65001`——均不保证所有环境有效，失败仍用上一段。

## 控制台与文件编码

- `print` 避免 emoji（GBK 终端易 `UnicodeEncodeError`），用「成功」「失败」等纯文本。
- 写 JSON 用 `ensure_ascii=False`，保证中文落盘正确。
