# 根据测试分析生成测试用例

## 目标

在已有 `test_analysis_content.json` 的前提下，生成与之对齐的 `test_cases_content.json`（场景覆盖可追溯）。

## 输入与输出

| 类型 | 说明 |
|------|------|
| 输入 | `test_analysis_content.json`；需求文档；`--product`；`pre_docs/<产品>/` 用例参考 |
| 输出 | `test_cases_content.json`（与 `test_analysis_content.json`、**`需求号-简述.md`** 同目录；目录名为 **`需求号-简述`**，见 [路径与编码约定.md](路径与编码约定.md)） |

## 可选字段 `analysis_ref`

每条用例可增写字段 `analysis_ref`（字符串），表示对应分析树上的节点路径或关键词，便于人工核对（脚本生成 MD/JSON 时可忽略，不影响格式输出）。

示例：

```json
{
  "case_name": "某功能-正常流",
  "analysis_ref": "测试场景/正常场景/具体场景名",
  "precondition": "...",
  "steps": "...",
  "expects": "..."
}
```

## 后置自查（post_docs）

- **产品侧**：`post_docs/<产品>/测试用例checklist.xlsx`（优先）或 `测试用例checklist.md`。
- **总清单**：`post_docs/checklist.md`；合并规则：**先总后产品，同章节以产品为准**。
- 兼容：若仅有旧文件名 `checklist.md` 仍可读取（建议迁移为 `测试用例checklist.md`）。

未通过时用 `--post-check-only` 快速重试（命令见入口 [SKILL.md](../SKILL.md) 或本包 `scripts/generate_from_requirement.py --help`）。
