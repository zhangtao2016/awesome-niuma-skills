## 🚀 快速开始

### 安装

```bash
# 一次性递归克隆（推荐）
git clone --recurse-submodules https://github.com/zhangtao2016/awesome-niuma-skills.git

# 或者浅克隆主仓库和子模块（节省时间/空间）
git clone --recurse-submodules --shallow-submodules https://github.com/zhangtao2016/awesome-niuma-skills.git

# 或者指定克隆深度（节省时间/空间）
git clone --recurse-submodules --depth 1 https://github.com/zhangtao2016/awesome-niuma-skills.git

# 进入目录
cd awesome-niuma-skills

# 查看所有技能
ls skills/
```

## 🎓 如何使用

### 方法一：直接查阅

```bash
# 找到你需要的Skill分类
cd skills/你想要的分类/子分类/技能名称

# 查看该Skill的详细说明
cat *.md
```

### 方法二：按需取用

每个Skill都是一个独立的工作流/模板/指南。你可以：

1. **直接使用**：复制粘贴到你的工作中
2. **修改定制**：根据你的实际情况调整
3. **组合创造**：多个Skill叠加使用效果更佳

### 方法三：贡献新Skill

```bash
# 1. Fork 本仓库
# 2. 创建你的Skill目录
mkdir -p skills/你的分类/你的Skill名称

# 3. 编写Skill内容
cat > skills/你的分类/你的Skill名称/README.md << 'EOF'
# 你的Skill标题

> 一句话描述

## 适用场景
...

## 使用方法
...
EOF

# 4. 提交PR，等待合并
```
