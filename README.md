## 🚀 快速开始

### 安装

```bash
# 克隆本仓库
git clone https://github.com/brizer/awesome-niuma-skills.git

# 进入目录
cd awesome-niuma-skills

# 查看所有技能
ls skill/
```


## 🎓 如何使用

### 方法一：直接查阅

```bash
# 找到你需要的Skill分类
cd skill/你想要的分类/子分类/技能名称

# 查看该Skill的详细说明
cat *.md
```

### 方法二：按需取用

每个Skill都是一个独立的工作流/模板/指南。你可以：

1. **直接使用**：复制粘贴到你的工作中
2. **修改定制**：根据你的实际情况调整
3. **组合创造**：多个Skill叠加使用效果更佳
